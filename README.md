# Ta3lam
# بوت تَعلّمْ — خطة البناء المجانية على جيت هب

## الهدف
بناء وتشغيل البوت **بدون كمبيوتر وبدون أي تكلفة**، كله من الموبايل.

## الأدوات (كلها مجانية)
| الغرض | الأداة |
|---|---|
| تخزين الكود والمحتوى | **GitHub** (موقع أو تطبيق الموبايل) |
| تعديل الكود من الموبايل | محرر GitHub على الموقع، أو **GitHub Codespaces** (حصة مجانية شهرية، تفتح من متصفح الموبايل) |
| تشغيل البوت 24 ساعة | **Cloudflare Workers** (نظام Webhook، لا ينام) |
| قاعدة بيانات تقدم المتعلمين | **Cloudflare D1** (SQLite مجاني) |
| النشر التلقائي | ربط مستودع GitHub بـ Cloudflare، وكل تعديل ينشر نفسه |
| إنشاء البوت نفسه | **@BotFather** داخل تليجرام |
| الصوتيات للأجانب (لاحقًا) | توليد ملفات صوتية مجانية مرة واحدة ورفعها كملفات ثابتة |

> حدود الخطط المجانية تتغير، فهراجعها على المواقع الرسمية قبل التنفيذ.

## المعمارية (مصممة لتتحول لتطبيق أندرويد)

```
 تليجرام ──► Webhook (Cloudflare Worker)
                  │
          ┌───────┴────────┐
          │  منطق التعليم  │  (مستقل عن تليجرام)
          │  - اختيار الدرس │
          │  - تصحيح الإجابة│
          │  - قرار التقدم  │
          │  - التكرار المتباعد
          └───────┬────────┘
        ┌─────────┴─────────┐
   content/*.json        D1 Database
   (الدروس والأسئلة)     (users, progress, reviews)
```

الفكرة: **منطق التعليم** يكون دوال مستقلة، وتليجرام مجرد واجهة. لاحقًا نضيف نقاط API (`/api/lesson`, `/api/answer`) فيستخدمها تطبيق أندرويد (Flutter أو React Native) بنفس المحتوى والمنطق وقاعدة البيانات.

## جداول قاعدة البيانات (schema.sql)

```sql
CREATE TABLE users (
  tg_id INTEGER PRIMARY KEY,
  track TEXT,            -- native | learner
  level TEXT,
  ui_lang TEXT DEFAULT 'ar',
  xp INTEGER DEFAULT 0,
  streak INTEGER DEFAULT 0,
  last_active TEXT
);
CREATE TABLE progress (
  tg_id INTEGER,
  lesson_id TEXT,
  best_score REAL,
  status TEXT,           -- locked | in_progress | passed
  PRIMARY KEY (tg_id, lesson_id)
);
CREATE TABLE reviews (
  tg_id INTEGER,
  question_id TEXT,
  box INTEGER DEFAULT 1,
  due_date TEXT,
  PRIMARY KEY (tg_id, question_id)
);
```

## خطوات البدء (من الموبايل)
1. **تليجرام**: ابعت `/newbot` لـ @BotFather، واحفظ **التوكن** (سر، لا يُنشر أبدًا).
2. **جيت هب**: أنشئ حسابًا ومستودعًا جديدًا (Private) باسم `Ta3lam`.
3. **كلاود فلير**: أنشئ حسابًا مجانيًا، وأنشئ قاعدة D1 وWorker، واربطه بالمستودع.
4. ضع التوكن في **Secrets** في إعدادات الـ Worker (ليس في الكود).
5. نرفع أول نسخة من الكود والدروس، ونضبط الـ Webhook على رابط الـ Worker.
6. جرّب البوت بنفسك، ثم ادعُ 5–10 أشخاص للتجربة.

> أنا هكتب لك الكود كاملًا ملفًا ملفًا، وإنت تنسخه في GitHub من الموبايل.

## الربح لاحقًا (عند الحاجة)
- قناة تليجرام مرتبطة بالبوت تجمع الجمهور وتخدم الإعلانات والرعايات.
- رسائل رعاة مدمجة بشكل خفيف (مثلًا رسالة واحدة بعد كل عدة دروس) بدل إعلانات مزعجة.
- تبرعات/اشتراك اختياري لميزات إضافية (شهادات، مراجعة مكثفة).
- نراجع القواعد الرسمية لتليجرام عن الإعلانات في البوتات قبل التنفيذ.
