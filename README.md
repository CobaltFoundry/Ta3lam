# تَعلّمْ · Ta3lam

بوت تليجرام (ميني آب) لتعليم اللغة العربية: من الصفر إلى الاحتراف، دروس قصيرة ثم اختبار ثم قرار تلقائي، ومراجعة متباعدة. مساران: للناطقين الراغبين في الإتقان، وللأجانب.

البوت: **@Ta3almAppBot**

## هيكل المشروع

| المجلد | الوظيفة |
|---|---|
| `app/` | واجهة الميني آب (HTML/CSS/JS بدون أدوات بناء) وتُنشر على GitHub Pages |
| `app/content/` | الدروس والفهرس (JSON) — **يُولَّد** من `tools/` |
| `worker/` | الخلفية على Cloudflare Workers + قاعدة D1 (التحقق من تليجرام، التقدم، المراجعة، التذكير اليومي) |
| `tools/` | بيانات المنهج ومولّد المحتوى والمدقق واختبار المتصفح |
| `docs/` | المنهج الكامل ودليل النشر |

## أوامر مفيدة

```bash
node tools/build-content.mjs        # يولّد الدروس ويتحقق منها
cd worker && npm test               # اختبارات الخلفية
python3 tools/e2e.py                # اختبار شامل للواجهة في متصفح حقيقي
node tools/sync-shared.mjs          # بعد تعديل worker/src/engine.js أو srs.js
```

## إضافة محتوى
- دروس الناطقين: `tools/data-native.mjs`
- دروس الأجانب: `tools/data-learner.mjs` وطريقة التوليد في `tools/build-content.mjs`
- بعد أي تعديل شغّل `node tools/build-content.mjs`؛ المدقق يرفض أي سؤال معطوب قبل النشر.

## النشر
راجع [`docs/DEPLOY.md`](docs/DEPLOY.md) (كله من الموبايل وبدون تكلفة).

## الأمان
- توكن البوت **لا يُكتب في الكود أبدًا**: يوضع كسرّ (Secret) في Cloudflare فقط.
- الخادم يتحقق من توقيع تليجرام (`initData`) في كل طلب.
